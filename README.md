# حضور و غیاب حلقه صالحین

اپلیکیشن بومی Android، کاملاً آفلاین و تک‌کاربره برای ثبت اعضا، جلسات، حضور و غیاب، امتیاز فعالیت، گزارش و پشتیبان‌گیری.

## ویژگی‌ها
- SQLite محلی؛ بدون اینترنت و بدون حساب کاربری
- رابط فارسی و RTL
- تقویم شمسی برای جلسات و تاریخ گزارش
- اعضا: افزودن، ویرایش، حذف، جستجو
- جلسات: افزودن، ویرایش، حذف
- حضور: حاضر / تأخیر / غایب، موجه/غیرموجه برای غایب، امتیاز ۰ تا ۱۰۰
- گزارش درصد حضور، تفکیک غیبت موجه/غیرموجه و رتبه‌بندی
- خروجی Excel-compatible با پسوند `.xls` (SpreadsheetML) و فایل پشتیبان JSON
- بازیابی پشتیبان و حذف همه داده‌ها

## ساخت APK
Android Studio 2024.3.2 یا جدیدتر، JDK 17، Android SDK 35 توصیه می‌شود. پروژه را باز کنید و `Build > Build APK(s)` را بزنید.

این نسخه هیچ وابستگی شخص ثالثی ندارد و برای اجرای آفلاین ساخته شده است.
